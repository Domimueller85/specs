# 🤝 Mitmachen — Contributing Guide

Danke, dass du mitmachen möchtest! Hier sind die wichtigsten Regeln auf einen Blick.

---

## 🔄 Der Weg einer Spezifikation

```
💡 Idee (Issue)
    ↓
✏️ Entwurf (specs/drafts/)
    ↓
🔍 Review (Pull Request)
    ↓
✅ Angenommen (specs/active/)
```

---

## 📝 Wie reiche ich etwas ein?

1. **💡 Idee** → Erstelle ein [Issue](.github/ISSUE_TEMPLATE/new_spec.md) mit der Vorlage
2. **✏️ Entwurf** → Lege eine Datei in `specs/drafts/` an (Namensformat: `wtf-XXXX-titel.md`)
3. **📬 Pull Request** → Öffne einen PR und beschreibe deine Änderung kurz
4. **🔍 Review** → Warte auf Feedback (wir antworten so schnell wie möglich)
5. **✅ Merge** → Nach Freigabe wird dein Entwurf in `specs/active/` verschoben

---

## 📏 Regeln für Pull Requests

- ✅ Ein PR = eine Änderung / eine Spezifikation
- ✅ Kurze, verständliche Beschreibung im PR
- ✅ Respektvoller Umgangston (siehe [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md))
- ❌ Keine massenweisen Änderungen ohne vorherige Diskussion
- ❌ Keine Änderungen an fremden Spezifikationen ohne Absprache

---

## 💬 Fragen?

Einfach ein Issue öffnen — kein Problem ist zu klein! 🙌
